DSH workflow-run UI

这是 DSH 自己的动态工作流 UI——它不是一个独立 tab 或浮层，而是对话流里的一个 chat node 卡片。

  • 两级折叠：Run → Phase → Member，都是 DisclosureRow
  • 状态驱动：有未完成 member 时自动展开
  • Member 可导航：运行中的 member 可点击，跳转到子代理会话
  • 事件驱动：tool-workflow/agent-start/end 事件实时更新
  • 无 DAG 图、无讨论面板、无产物——只有名称 + 状态 + 成员数

因为 DSH 的 workflow 工具是前台同步的——AI 调工具，工具阻塞等待完成，结果回到对话流。
